# MiniGame09 — 2048 / 128 만들기

- 4×4 보드에서 WASD로 타일 전체를 해당 방향으로 밀고 같은 값을 합칩니다.
- 시작 시 서로 다른 두 칸에 2 타일을 생성합니다. 유효한 이동 후 빈칸 중 한 곳에 2 타일 하나만 균등 무작위로 생성합니다. 4 타일은 생성하지 않습니다.
- 무효 이동은 새 타일이나 이동 횟수를 만들지 않습니다. 한 입력에서 각 타일은 한 번만 합쳐집니다.
- 128을 만드는 즉시 성공하며 성공 이동 뒤에는 새 타일을 생성하지 않습니다.
- 빈칸도 인접한 같은 숫자도 없으면 즉시 실패합니다. 제한 시간은 없습니다.
- 새 눌림당 한 번 움직입니다. 동시 입력은 기존 게임과 같은 W→A→S→D 우선순위입니다.
- 시작·Tab 정지/재개·Space 재시도·결과 1회 통지는 기존 MiniGameController/MiniGameTestUI를 사용합니다.
- Z+X+C는 에디터/개발 빌드용 성공 스킵입니다. 출시 시 Merge2048Game.cs의 DEV_CLEAR_CHEAT #if~#endif 블록만 제거할 수 있습니다.

구조: Merge2048Model(보드·병합·생성), Merge2048Game(공통 계약 연결), Merge2048View(16칸 숫자/색상 표시).
애니메이션과 별도 타이머는 없으며 타일 Image와 전용 정적 TMP 글꼴은 교체 가능합니다. ScreenSpaceCamera/CanvasScaler로 기존 Additive 뷰포트에 맞춥니다.

Tools > Mini Games > 09 2048 > Open or Create Scene으로 씬을 열 수 있습니다. 이미 존재하는 씬은 빌더가 덮어쓰지 않습니다.
