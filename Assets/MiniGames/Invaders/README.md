# MiniGame06 — 우주 방어전

MiniGame05와 같은 구조를 따른다. `InvadersGame : MiniGameController`가 기존 시작·정지·재개·결과·재시도 API를 사용하고 `MiniGameTestUI`가 상태 화면을 표시한다. `InvadersModel`은 로컬 규칙, `InvadersView`는 화면 갱신을 담당한다.

## 실행과 조작

- `Assets/Scenes/MiniGame06.unity`를 열고 Play → Space로 시작한다.
- 기존 공통 입력 정책에 따라 시작/재개 시 누른 키는 한 번 놓고 다시 누른다.
- A/D는 누르는 동안 좌우 이동한다. 동시에 누르면 이동하지 않으며 W/S는 무시한다.
- Space는 누르는 동안 0.4초 간격으로 발사한다. 해제·재입력으로 대기시간을 초기화하지 않는다.
- Tab 정지/재개와 성공·실패 후 Space 재시도는 기존 공통 코드를 그대로 사용한다.
- 에디터/Development Build에서 Z+X+C를 동시에 새로 누르면 기존 게임과 동일하게 성공 처리한다. 출시 시 `DEV_CLEAR_CHEAT`의 `#if~#endif` 블록을 제거할 수 있으며 일반 빌드에서는 자동 제외된다.

## 확정 규칙

- 3행×6열, 18기. 중심 X는 100부터 80 간격, Y는 76부터 56 간격이다.
- 편대는 오른쪽부터 이동하며 속도는 `32 + 처치 수 × 2`다. 생존한 바깥 적의 외곽이 경계에 닿으면 위치를 보정하고 22 내려간 뒤 반전한다. 빈자리는 채우지 않는다.
- 적 발사는 시작 2.5초 후 첫 발, 이후 편대 전체에서 0.55초마다 한 발이다(기존 1.1초에서 50% 단축). 각 열 최하단 생존 적 중 균등 추첨하며 아래로 직진한다.
- 방어막 중심 X 180/420, 상단 Y 370. `01110 / 11111 / 11011`의 5×5px 조각 12개씩으로 전체 배치 영역은 25×15px다(기존 가로·세로 각각 50% 축소). 표시와 충돌 크기가 함께 줄어든다. 양쪽 탄환 모두 최초 접촉 조각 한 개와 탄환만 제거한다. 적이 겹치면 해당 조각만 부순다.
- 사용자 확인에 따라 **내부 목숨은 1개**다. 한 번 피격되면 `기체 격추`로 미니게임 실패를 전달한다. 외부 목숨은 이 코드에서 변경하지 않는다.
- 생존한 피격에 대한 1.2초 무적·점멸 처리도 모델에 있지만 기본 목숨 1개에서는 즉시 실패하므로 사용되지 않는다. 무적 중 접촉 탄환은 제거한다.
- 적 하단이 방어선에 닿으면 목숨과 관계없이 `방어선 돌파`로 실패한다. 마지막 적을 처치하면 즉시 성공한다.
- 재시도는 모든 적·방어막·탄환·내부 목숨·속도·타이머를 초기화한다.

## 명시되지 않은 값의 초기 설정

좌상단 원점 픽셀 좌표를 사용한다. 플레이 영역은 600×480, 좌우 경계는 X 20/580, 방어선은 Y 420, 플레이어 중심 Y는 440이다. 플레이어와 적 크기는 32×24, 탄환은 4×10이다. 충돌은 외곽 사각형 기준이다.

`InvadersGame > Rules`에서 플레이어 속도 220px/s, 플레이어 탄속 420px/s, 적 탄속 180px/s, 내부 목숨과 난수 시드를 확인할 수 있다. 난수 시드 -1은 매 시도 무작위다. 제시된 편대/발사 규칙의 상수는 `InvadersRules`에 모았다.

아트는 전용 픽셀 도형 `Ship.png`, `Enemy.png`와 단색 UI로 구성한다. 씬 Image의 Sprite를 팀원 아트로 교체할 수 있다. 공용 아트/폰트는 변경하지 않았고 전용 정적 한글 폰트를 사용한다. 무적 점멸 외 별도 연출 애니메이션은 없다.

## 씬 연결과 검증

- 기존 파일 변경은 `MainGame.unity`의 미니게임 선택 목록 한 줄, `EditorBuildSettings.asset`의 MiniGame06 씬 등록뿐이다. 전체 매니저·공통 코드·기존 미니게임은 수정하지 않는다.
- 제작 도구: `Tools > Mini Games > 06 Invaders > Open or Create Scene`. 이미 존재하는 씬을 재생성하지 않고 열기만 한다.
- Unity 6000.3.23f1의 격리 프로젝트에서 EditMode 14/14, URP PlayMode 4/4 통과. 실제 키보드 경로, 공통 결과/재시도, ZXC 치트, 가로·세로·축소 viewport를 검증했다.
- 원본 메인게임 전체 실행은 작업 범위에 포함하지 않았다. 실제 사람이 느끼는 난이도는 후속 플레이테스트로 조정한다.
