# MiniGame08 — DANCE

GE_DANCE.html의 방향 순서 맞추기 게임을 기존 미니게임 계약으로 옮겼습니다.

- WASD로 왼쪽부터 방향 순서를 입력해 10라운드를 완료합니다. 각 칸은 네 방향 중 독립 무작위이며 같은 방향이 연속으로 나올 수 있습니다.
- 1~3라운드: 4개/4.8초, 4~6라운드: 6개/7.2초, 7~9라운드: 8개/9.6초, 10라운드: 10개/12초.
- 새 눌림당 한 번만 입력합니다. 동시 입력 우선순위는 기존 스네이크와 같은 W→A→S→D입니다. 플레이 중 Space는 무시합니다.
- 한 줄 완료 후 0.4초 동안 입력과 제한 시간을 멈추고 다음 줄을 생성합니다. 추가 입력으로 중복 진행하지 않습니다. 마지막 줄은 즉시 성공합니다.
- 잘못된 방향/시간 초과는 공통 실패 처리로 연결됩니다. 원본 HTML의 자동 1라운드 복귀 대신 Space 재시도로 1라운드부터 다시 시작합니다.
- Tab 일시정지·재개는 입력, 제한 시간과 라운드 전환 대기를 함께 멈춥니다. 공통 상태·재시도 UI를 그대로 사용합니다.
- Z+X+C는 에디터/개발 빌드 성공 치트입니다. 출시 시 DanceGame.cs의 DEV_CLEAR_CHEAT #if~#endif 블록을 제거할 수 있습니다.

구조: DanceModel(규칙·시간·라운드), DanceGame(공통 계약 연결), DanceView(정적 UI 표시).
800×450 화면은 ScreenSpaceCamera와 CanvasScaler로 뷰포트에 맞춥니다. 방향은 화살표와 WASD 문자로 함께 표시합니다. 별도 애니메이션·효과음은 추가하지 않았고 원형 캐릭터/배경은 교체 가능한 Image입니다. 글꼴은 DANCE 전용 정적 에셋입니다.

Tools > Mini Games > 08 Dance > Open or Create Scene으로 씬을 열 수 있습니다. 이미 있는 씬은 빌더가 덮어쓰지 않습니다.
